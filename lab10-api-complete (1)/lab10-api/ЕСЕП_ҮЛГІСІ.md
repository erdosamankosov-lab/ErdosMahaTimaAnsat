## Жобаның файлдары

## Эндпоинттер
| Әдіс | URL | Код |
|---|---|---|
| GET | /api/courses | 200 |
| GET | /api/courses/:id | 200 / 404 |
| POST | /api/courses | 201 / 400 |
| PUT | /api/courses/:id | 200 / 400 / 404 |
| DELETE | /api/courses/:id | 204 / 404 |
| PATCH | /api/courses/:id | 200 / 400 / 404 |

## Скриншоттар
Мына нақты тесттердің скриншоттарын осында енгізіңіз: GET тізім, GET id, POST, PUT, DELETE, PATCH, сүзгілеу, қате POST (400), жоқ id (404), жоқ маршрут (404). Скриншоттар әдейі жасалған жоқ — оларды сервер іске қосылғаннан кейін түсіріңіз.

## Бақылау сұрақтарына жауаптар
1. **Node.js** — JavaScript кодын браузерден тыс, серверде орындау ортасы. Браузер JS-і DOM-мен жұмыс істейді, Node.js файлдармен және желімен жұмыс істей алады.
2. **Express** — Node.js веб-фреймворкі. Маршрут — HTTP әдісі мен URL жолына сәйкес келетін өңдеуші.
3. `req.params` — URL ішіндегі параметрлер, `req.query` — `?` таңбасынан кейінгі параметрлер, `req.body` — сұраныс денесі.
4. **Middleware** — сұранысты өңдеу тізбегіндегі функция. `next()` келесі өңдеушіге өтеді; реті маңызды, себебі middleware жоғарыдан төмен орындалады.
5. Қате өңдеушісінің төрт параметрі бар: `(err, req, res, next)`; кәдімгі middleware-де үшеу.
6. REST ресурстарды URL арқылы көрсетеді, стандартты HTTP әдістерін және күй кодтарын қолданады. URL-де зат есім қолдану ресурс пен әрекетті бөледі.
7. PUT толық, PATCH ішінара жаңартады. POST сәтті жасалғанда 201, DELETE сәтті жойғанда 204 қайтарады.
8. Клиенттік валидацияны айналып өтуге болады, сондықтан сервер міндетті түрде тексеруі тиіс.

## Қорытынды
Express негізінде CRUD REST API әзірленді. Жобаға JSON парсері, логгер, валидация, 404 және жалпы қате өңдеушісі қосылды. Қосымша PATCH, пагинация, CORS және бөлек Router қолданылды. Нақты орындалған тест нәтижелері мен скриншоттарын тіркеу қажет.
